# Hand-Watch-Design
# Design and Assemply of hand watch (Creo 8.0)

![Main Render](05.jpeg)

## 📋 Project Overview
This repository contains the 3D CAD files for a mechanical wristwatch assembly designed using *PTC Creo Parametric 8.0*. The project demonstrates the full design workflow, from initial hand-drawn drafting sketches with calculated dimensions to a fully constrained 3D assembly.

The design features a classic analog face and a multi-link metal bracelet, showcasing assembly management and part modeling techniques.

## 🛠️ Software & Tools
* *CAD Software:* PTC Creo Parametric 8.0
* *Modeling Techniques:* Extrusions, Revolves, Patterning, Assembly Constraints.

## 📐 Design Specifications
Based on the initial engineering sketches, the watch was designed with the following dimensions:

| Component | Dimension |
| :--- | :--- |
| *Case Diameter (Outer)* | 42 mm |
| *Case Diameter (Inner/Face)* | ~33 mm |
| *Lug-to-Lug Distance* | 48.5 mm |
| *Strap/Lug Width* | 18 mm |
| *Link Dimensions* | 6mm (H) x 8mm (W) x 2mm (D) |
